## Cross-cutting observations

- All six production flows have a real implementation path; all six gallery Blocks are reference fixtures, not the product screens. Existing component sharing is not proof of completed coverage.
- Product desktop and phone captures are retained. Checked scenario and run pages have matching `innerWidth`/`scrollWidth` at both widths; the gallery Blocks visibly clip horizontally at phone width. Wide tables should scroll within a labeled region where needed.
- The initial lesson screenshots caught a transient map loading state. A later loaded-map capture resolved it, so this audit records no map defect from those early frames.
- This pass did not complete the full shell/Learn/Labs, light/dark, reduced-motion, keyboard, print, access-state or recovery-state acceptance. Those remain candidate-verification work.
- Product-side implementation fixes and post-change captures remain outstanding. These records are a baseline audit, not M8 sign-off.
